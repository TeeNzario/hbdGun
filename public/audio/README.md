# Optional audio files

The site already creates a quiet procedural rain-and-wind soundscape with Web
Audio. To use recorded audio later, add these files:

- `rain.mp3`
- `forest.mp3`
- `wind.mp3`
- `piano.mp3`
- `chime.mp3`
- `collect.mp3`
- `finale.mp3`

The replacement paths are documented in `src/data/memories.ts`.
